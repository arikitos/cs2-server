# Warcraft Classic

The plugin source is [arikitos/cs2-warcraft3](https://github.com/arikitos/cs2-warcraft3). The repository currently builds its release archive from the normal `addons/counterstrikesharp/plugins/WarcraftClassic` path. Extract that output directly here.

PanelBridge and ClutchAnnounce are bundled in the same mode. Runtime data created by WarcraftClassic is not part of the copied inventory and survives mode switches. Operator configuration is stored under `server/state/configs/warcraft`.
